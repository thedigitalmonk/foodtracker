# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the app follow the OS dark/light preference automatically using Tailwind's `"media"` dark mode strategy.

**Architecture:** Switch Tailwind from class-based to media-query dark mode. Move the existing `.dark` CSS variable block in `globals.css` to a `@media (prefers-color-scheme: dark)` rule. Replace hardcoded hex colors throughout the app with semantic Tailwind classes (e.g. `bg-background`, `text-foreground`) that already map to the CSS variable palette — so dark mode works automatically with zero JS.

**Tech Stack:** Next.js 14, Tailwind CSS 3, CSS custom properties (HSL)
